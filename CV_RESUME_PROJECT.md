- Orchestration de microservices sur Kubernetes avec service discovery natif

## 📊 Architecture Overview

### Microservices Architecture Pattern
The project follows a complete microservices architecture with:
- **Service Discovery**: Automatic service registration and discovery using Netflix Eureka
- **API Gateway**: Centralized entry point for all client requests with routing and cross-cutting concerns
- **Config Server**: External configuration management for all microservices
- **Resilience**: Circuit breakers, retries, rate limiters, and bulkhead patterns
- **Observability**: Distributed tracing, metrics collection, and log aggregation
- **Security**: OAuth2/OIDC authentication and authorization with Keycloak

### Cloud-Native Deployment
- **Docker**: Containerization of all microservices
- **Kubernetes**: Production-grade orchestration with deployments, services, and configmaps
- **Helm**: Package management and templating for Kubernetes deployments
- **Service Mesh**: Advanced traffic management with Istio

### Event-Driven Architecture
- **RabbitMQ**: Lightweight message broker for async communication
- **Apache Kafka**: High-throughput distributed event streaming platform
- **Spring Cloud Functions**: Functional programming model for event processing
- **Spring Cloud Stream**: Framework for building event-driven microservices
