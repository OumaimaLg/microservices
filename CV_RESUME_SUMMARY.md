## 🎓 Version pour Lettre de Motivation

### Français
Dans le cadre de mon développement professionnel, j'ai conçu et réalisé une architecture microservices d'entreprise complète utilisant les technologies Spring Boot 3.4, Docker et Kubernetes. Ce projet m'a permis d'approfondir ma maîtrise des patterns de conception microservices modernes, notamment le Service Discovery avec Eureka, l'API Gateway, et les patterns de résilience comme le Circuit Breaker et le Rate Limiting.

J'ai également implémenté une architecture event-driven complète utilisant RabbitMQ et Apache Kafka, permettant une communication asynchrone et scalable entre les microservices. L'observabilité du système a été assurée grâce à l'intégration de Grafana, Prometheus et OpenTelemetry, offrant une visibilité complète sur les performances et le comportement de l'application.

La sécurisation de l'ensemble a été réalisée avec Keycloak pour la gestion OAuth2/OIDC, et le déploiement sur Kubernetes avec Helm Charts démontre ma capacité à mettre en œuvre des solutions cloud-native production-ready.

### English
As part of my professional development, I designed and implemented a comprehensive enterprise microservices architecture using Spring Boot 3.4, Docker, and Kubernetes technologies. This project allowed me to deepen my mastery of modern microservices design patterns, including Service Discovery with Eureka, API Gateway, and resilience patterns such as Circuit Breaker and Rate Limiting.

I also implemented a complete event-driven architecture using RabbitMQ and Apache Kafka, enabling asynchronous and scalable communication between microservices. System observability was ensured through integration with Grafana, Prometheus, and OpenTelemetry, providing complete visibility into application performance and behavior.

Security was achieved with Keycloak for OAuth2/OIDC management, and deployment on Kubernetes with Helm Charts demonstrates my ability to implement production-ready cloud-native solutions.
